Install Mom Shop

Adds an icon to your home screen. Opens full-screen like an app.

Android (Chrome)
  1. Open this site in Chrome
  2. Tap ⋮ menu > Add to Home screen or Install app
  3. Confirm Add — icon appears on home screen
iPhone (Safari — required)
  1. Open this site in Safari (not Chrome)
  2. Tap Share ⬆ > Add to Home Screen
  3. Tap Add — icon appears on home screen

iPhones cannot install from Chrome — must use Safari.
